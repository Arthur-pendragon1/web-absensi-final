# Security Policy

## Supported Versions

The project is currently maintained for the latest working version in the active branch.

## Reporting a Vulnerability

Please report security issues privately and responsibly.

- Send details to the maintainer via email or a private channel.
- Do not open a public GitHub issue for security vulnerabilities.
- Include reproduction steps, impact, and any suggested remediation if available.

We aim to review and respond to valid reports as quickly as possible.

## Best Practices

- Do not publish API keys, OAuth secrets, or database credentials.
- Rotate credentials immediately if they were exposed.
- Keep the PHP, MySQL, and library dependencies updated.
- Review access control and admin permissions before production deployment.
